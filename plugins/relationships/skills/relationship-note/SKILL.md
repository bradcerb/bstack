# Relationship note

Log a real connection so you can follow through without turning people into pipeline fodder.

## Rules

- Facts only: who, where, what mattered, what you offered or owe.
- Next touch should be generous or useful, not a pitch by default.
- Draft only. No CRM write without go.
- Never invent mutuals or private details.
- Never use em-dashes.

## Steps

1. Capture name, org, context, date.
2. Note the hook and any promise made.
3. Suggest one next touch (thank-you, intro, resource) with timing.
4. File where the author keeps relationship notes.

## Completion

Short note + suggested next touch. Human decides whether to send.
