# Decision log

Capture a decision so the team (or future you) knows what was chosen and why.

## Rules

- One decision per entry.
- Include options considered and why not.
- Name owner and revisit date when useful.
- Don’t invent consensus. Note dissent if the author says so.
- Never use em-dashes.

## Steps

1. Title the decision in one line.
2. Context (3-5 lines).
3. Options (bullets) + choice.
4. Consequences / risks acknowledged.
5. Owner, date, revisit date.
6. Save where the author keeps decisions (doc, Notion, repo ADR). Do not create secret stores.

## Completion

A single decision entry ready to paste or file.
