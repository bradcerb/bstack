# Feedback draft

Draft clear, behavior-based feedback. The author delivers it; you don’t.

## Rules

- Situation → Behavior → Impact → Ask (or next step).
- Specific and recent. No character attacks.
- Separate facts from interpretation.
- Draft only. Timing and delivery are human judgment.
- Never use em-dashes.

## Steps

1. Confirm intent: praise, course-correct, or both.
2. Gather concrete examples from the author.
3. Draft a spoken version (short) and optional written version.
4. Flag anything that needs HR / policy review.
5. Stop for the author’s edit.

## Completion

Paste-ready draft + flags. No send.
