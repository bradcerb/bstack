# One-on-one

Prepare a useful 1:1 agenda and follow-ups. Based on common managerial practice (regular cadence, their agenda first, coaching over status-only).

## Rules

- Their topics first when possible.
- Balance delivery, career, and wellbeing. Don’t turn it into only status.
- Draft agenda and notes. Do not book calendar or send without go.
- Never invent performance claims. Ask for evidence.
- Never use em-dashes.

## Steps

1. Pull open threads from last 1:1 (or ask).
2. Ask what they want on the agenda.
3. Draft a short agenda (5-7 bullets max).
4. After the meeting (from notes): decisions, commitments, dates.
5. Draft a private follow-up for the manager’s file and optional shared note.

## Completion

Agenda and/or follow-up draft. Human owns the conversation.
