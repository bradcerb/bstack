# Draft never send

Outbound copy is draft + pulse only.

## Rules

- Never post, like, reply, send, publish, connect, or submit until the user explicitly says go.
- Stay silent when there is nothing to draft or report.
- Send-on-behalf is override-only after that explicit go  -  not the default path.
- Return paste-ready draft text the user can copy.
- Name the channel (email, X, LinkedIn, CRM, marketplace, etc.) in the delivery so they know where it belongs.

## Related

- **Send on behalf** only after go.
- **Social post formats** for short public drafts.
- **Owner voice** before drafting as the author (portable). Prefer **House voice** on this seat when Brad's style paths are in memory.
