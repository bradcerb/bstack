# Clear ask

Turn a fuzzy need into a short message with a crisp ask.

## Rules

- Draft only. Do not send (see **draft-never-send**).
- One primary ask per message.
- Lead with the ask or the decision needed.
- Include context the reader lacks, not a full history.
- Name a deadline or “by when” when it matters.
- Never use em-dashes. No filler openers.

## Steps

1. Confirm audience, ask, and desired response.
2. Draft in the author’s voice if a style guide exists; otherwise plain and direct.
3. Check: can the reader say yes/no/choose in one reply?
4. Deliver paste-ready text and name the channel.

## Completion

Paste-ready draft + one-line note on the ask and deadline.
