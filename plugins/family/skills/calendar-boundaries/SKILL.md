# Calendar boundaries

Turn “protect evenings and weekends” into concrete calendar rules and decline language.

## Rules

- Draft holds and decline scripts. Do not edit the live calendar without go.
- Exceptions should be rare and named.
- Kind and clear beats apologetic essays.
- Never use em-dashes.

## Steps

1. Confirm protected windows and exception types.
2. Draft decline / reschedule language in the author’s voice.
3. Suggest buffer blocks before/after deep work or travel.
4. List this week’s conflicts and proposed moves.

## Completion

Rules + scripts + proposed moves for author approval.
