# Weekly review

A short weekly review for personal and freelance work.

## Rules

- Three priorities max for next week.
- Celebrate shipped work without theater.
- Move stuck items: kill, schedule, or ask for help.
- Never use em-dashes.

## Steps

1. List shipped / progress / stuck.
2. Clear tiny open loops (or park them).
3. Choose next week’s top three.
4. Note calendar boundaries to protect.
5. Stop.

## Completion

Shipped / stuck / next-three summary.
