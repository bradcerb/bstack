# Project brief

One page to start a side or freelance project without boiling the ocean.

## Rules

- Outcome and non-goals matter as much as scope.
- No Triumph/org PM process here. Keep it personal/freelance-light.
- Draft only; don’t create tickets unless asked.
- Never use em-dashes.

## Steps

1. Name the project and success metric.
2. In scope / out of scope.
3. Milestones (3-5) with rough dates.
4. Risks and open questions.
5. Next action this week.

## Completion

One-page brief ready to paste.
