# Leave-behind check

Quick QA before a one-pager or leave-behind goes to print or PDF.

## Rules

- Check hierarchy, margins, and contrast. Don’t redesign unless asked.
- Flag missing contact path and single clear CTA.
- Note print risks (bleeds, tiny type, low-contrast icons).
- Never use em-dashes.

## Steps

1. Confirm audience and one job of the piece.
2. Scan: headline → proof → CTA → contact.
3. Check mobile/PDF readability if it’s also digital.
4. List must-fix vs nice-to-fix.
5. Stop for the author’s design seat to implement.

## Completion

Short checklist with pass/fail and must-fix items.
