# Cloud agent handoff

Hand non-trivial repo work to a cloud or async coding agent instead of editing line-by-line in chat.

## Do

- Hand off problem + outcome, not line-by-line edits.
- Never clone a repo just to look around.
- Follow-ups: reply to the same agent.
- Run compile and E2E on a real machine or pool when the stack needs it.
- After PR, verify on a real surface (preview URL, plugin install, staging).

## Out of scope

Figma, critique, SEO briefs, inbox, pure connector ops.

Prefer the host’s standard code-change skill alongside this one when available.
