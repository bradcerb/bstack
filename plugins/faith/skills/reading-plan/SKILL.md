# Reading plan

Build a realistic reading plan the author can keep.

## Rules

- Pace for real life. Missed days are normal.
- Author chooses the text and translation/edition.
- Portable across traditions.
- Never use em-dashes.

## Steps

1. Confirm text, start date, and minutes-per-day budget.
2. Propose a simple schedule (daily/weekly chunks).
3. Add a light check-in question each week.
4. Stop for their edit.

## Completion

Schedule table + weekly check-in question.
