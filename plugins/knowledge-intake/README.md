# knowledge-intake (bstack plugin)

Portable Notion-first knowledge capture and wiki ingest skills.

Install from **[bradcerb/bstack](https://github.com/bradcerb/bstack)** under `plugins/knowledge-intake/`. The older standalone repo [bradcerb/knowledge-intake-skills](https://github.com/bradcerb/knowledge-intake-skills) remains usable; prefer this path for new installs.

See the root [ARCHITECTURE.md](../../ARCHITECTURE.md) and this folder's `examples/` for setup. Skills that read a source check your `workspace.json` first and ask only for the fields they need. The full field list is the repo [examples/workspace.json.example](../../examples/workspace.json.example). This plugin's copy is [examples/workspace.json.example](./examples/workspace.json.example).
