# Purchase pause

A short pause before money leaves for something that was not in this month’s plan.

## Rules

- Calm and plain. No shame language.
- Ask price, category, and whether it fits the current margin plan.
- Educational decision frame, not advice. They decide.
- Draft-never-send if drafting a “decline” or “hold” message to a seller.
- Never store card numbers or credentials.
- Never use em-dashes.

## Steps

1. Capture: what, price, why now, and whether it is already in the margin plan.
2. Run three lanes:
   - **Need** - required for work, safety, health, or a hard deadline; delaying costs more.
   - **Wait** - want it; can delay 24 hours to 30 days; check cushion and debt extras first.
   - **Yes** - fits the plan (or they move money from another category on purpose).
3. If Wait: name the wait length and what would change the call (price drop, plan room, partner OK).
4. If Yes: name which category funds it so the month still zeros out.
5. One sentence recommendation frame + their choice. Stop.

## Completion

Need / wait / yes call + funding note if yes. Human buys or doesn’t.
