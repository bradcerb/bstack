# Debt order

List debts and pick an attack order. Default is **smallest balance first** (clear wins, free up cash flow). Optionally show **largest APR first** math so they choose with eyes open.

## Rules

- **Ask for balances, minimums, and APRs.** Do not scrape banks or store credentials.
- Never store card numbers, SSNs, or passwords.
- Educational comparison, not advice. They choose the order.
- Keep paying minimums on all debts unless they say otherwise with a professional.
- Draft-never-send for creditor emails or calls scripts.
- Never use em-dashes.

## Steps

1. Inventory each debt: name, balance, minimum, APR (if known), due day.
2. Sort A: smallest balance → largest. Name the first target and the extra payment they can put on it after minimums.
3. Sort B (optional): highest APR → lowest. Rough months/interest contrast in plain language if they have APRs; if not, say so and skip precision.
4. Present both orders side-by-side when they want the compare. Ask which order they want this month.
5. One next action: which debt gets the extra, and by when.

## Completion

Debt list + chosen order (or both views) + one next action. Human pays and confirms.
