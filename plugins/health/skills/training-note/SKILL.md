# Training note

Log a session so patterns show up. A coach seat or human coach owns the plan.

## Rules

- Keep it short. Facts + feel + one cue.
- No medical diagnosis. Suggest professional care when pain is sharp or new.
- Never use em-dashes.

## Steps

1. Capture sport/session, duration, main sets or efforts.
2. Note RPE / how it felt (one line).
3. Note one thing to repeat or fix next time.
4. File where the author tracks training.

## Completion

Short note ready to paste.
