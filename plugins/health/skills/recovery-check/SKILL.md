# Recovery check

A light check before stacking hard days.

## Rules

- Not medical advice. Red-flag symptoms → see a professional.
- Ask; don’t assume wearable data unless provided.
- Recommend back-off options, not heroics.
- Never use em-dashes.

## Steps

1. Ask sleep, soreness, mood/stress, upcoming load.
2. Sort: green / yellow / red for today’s hard work.
3. Suggest one adjustment (swap, shorten, rest).
4. Stop.

## Completion

Color call + one adjustment.
