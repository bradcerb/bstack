# Social post formats

Read the **House voice** skill first. Every draft comes back as actual paste-ready text. See also **Draft never send**.

## Real work only

Draft only from something the author actually built, shipped, or lived. Never invent a position or a build. If there is nothing real this week, say so and stay quiet.

## X

Short. A real line.

A few bullets only when a release genuinely has several features. A tired-but-true line is fine.

## LinkedIn

Longer narrative:

1. Hook or contrast.
2. One-sentence paragraphs.
3. A real moment.
4. Close on a reflection or a question.

## Social Listening (scored replies)

Scored replies and rare quote-with-thought. Still never post  -  formats still apply to short paste-ready drafts the author can send themselves.

- Default to a scored reply when engaging someone else's post.
- Quote-with-thought stays rare; only when the author has a real angle, not a dunk or a restatement.
- Same paste-ready delivery and **Draft never send** rules.

## Both

Short, declarative, confident full sentences. Warm, not slick. Builder detail from someone who did the thing. Specific names, versions, features. Credit people by name.

Hashtags rare. AI with practitioner detail, not hype.

## Never

- Generic LinkedIn voice.
- Product 101 explainers for an audience that already knows.
- Guru posture.
- "Not X, it's Y."
- Named traps and secrets.
- Restating a list in prose.

Quote-posts stay rare. Default to a reply or a comment.

## Done means

Paste-ready text the author can post as themselves, tied to a real thing, passing the coffee-shop test. Draft only. Never post, like, reply, or quote until the author says go.
